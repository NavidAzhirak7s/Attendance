# سامانه محاسبه حضور و غیاب ماهانه

یک ابزار سبک و فارسی برای ثبت و محاسبه حضور و غیاب ماهانه با پشتیبانی از تقویم شمسی سال ۱۴۰۵.

## امکانات

- انتخاب ماه و سال شمسی
- ثبت ساعت ورود و خروج روزانه
- تبدیل خودکار ورودی‌هایی مثل `09` و `16` به `09:00` و `16:00`
- محاسبه حضور، کسرکار، اضافه‌کار و خالص کارکرد
- ثبت مرخصی روزانه
- ثبت حداکثر سه بازه مرخصی ساعتی برای هر روز
- نمایش مقدار مرخصی استفاده‌شده به‌صورت ساعت و دقیقه
- کنترل مرخصی خارج از ساعات موظفی
- ورود به فیلد بعدی با کلیدهای `Enter` و `Tab`
- نگهداری اطلاعات هر ماه در `localStorage` مرورگر
- فیلتر روزهای کاری، کسرکار، اضافه‌کار و انواع مرخصی
- خروجی گرفتن از اطلاعات در قالب CSV
- محاسبه ساعات موظفی هر ماه بر اساس جدول سال ۱۴۰۵
- رابط کاربری فارسی و راست‌به‌چپ

## اجرای پروژه

این پروژه به نصب وابستگی یا سرور نیاز ندارد.

1. مخزن را دریافت یا Clone کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. ماه را انتخاب کنید و اطلاعات ورود، خروج و مرخصی را ثبت کنید.

برای تجربه بهتر در VS Code می‌توانید از افزونه Live Server نیز استفاده کنید.

## نحوه استفاده

### ساعت ورود و خروج

می‌توانید ساعت را به یکی از شکل‌های زیر وارد کنید:

- `09`
- `16`
- `09:30`
- `1630`

پس از خروج از فیلد، مقدار به قالب کامل ساعت و دقیقه تبدیل می‌شود.

### مرخصی ساعتی

برای هر روز سه جفت فیلد مرخصی وجود دارد:

- مرخصی از ۱ و مرخصی تا ۱
- مرخصی از ۲ و مرخصی تا ۲
- مرخصی از ۳ و مرخصی تا ۳

برای حذف هر بازه، از دکمه حذف کنار فیلد پایان همان بازه استفاده کنید. زمان مرخصی باید داخل محدوده ساعت ورود پیش‌فرض تا پایان موظفی باشد.

### موجودی مرخصی

موجودی مرخصی در بالای صفحه بر اساس «روز» و «ساعت» وارد می‌شود. مقدار مصرف‌شده و موجودی باقی‌مانده نیز در صفحه نمایش داده می‌شود.

## ساختار پروژه

```text
AttendanceDailyInfo/
├── index.html       # ساختار صفحه و جدول
├── Attendance.css   # استایل و طراحی رابط کاربری
├── Attendance.js    # منطق تقویم، محاسبات و ذخیره‌سازی
└── README.md        # راهنمای پروژه
```

## انتشار در GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. فایل‌های پروژه را در Repository قرار دهید.
3. از بخش `Settings > Pages`، شاخه اصلی Repository را برای انتشار انتخاب کنید.
4. پس از فعال شدن Pages، لینک ایجادشده را برای اجرای آنلاین پروژه استفاده کنید.

## نکات

- اطلاعات در مرورگر و برای هر ماه به‌صورت جداگانه ذخیره می‌شود.
- پاک کردن داده‌های مرورگر یا `localStorage` اطلاعات ثبت‌شده را حذف می‌کند.
- داده‌های ساعات موظفی فعلاً برای سال ۱۴۰۵ تعریف شده‌اند.
